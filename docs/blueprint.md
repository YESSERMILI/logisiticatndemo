# **App Name**: 3ez El Mondial by TT

## Core Features:

- User Authentication: Secure user registration and login functionality, including phone number authentication.
- Quick Quiz Gameplay: Core quiz mechanics allowing users to answer multiple-choice questions within a time limit and receive immediate scoring feedback.
- Quiz Category & Selection: Browse available quiz categories (e.g., Football, Tunisia) and select specific quizzes to play.
- Global Leaderboards: Display real-time global rankings of top players across daily, weekly, and all-time categories.
- User Profile & Achievements: Personalized user profile showing points, rank, progress, achievements, and quiz history.
- AI Quiz Question Generator: An AI tool to dynamically generate fresh and relevant quiz questions based on selected themes like sports, culture, and general knowledge, ensuring diverse content.
- Multi-language Support: Ability to toggle the application's interface and content between Arabic and French for localized user experience.

## Style Guidelines:

- Primary Blue: #0072CE (HSL: 207, 100%, 40%) selected for its vibrant, sporty, and competitive feel, mirroring Tunisie Telecom's brand identity.
- Background: #F5F7FA (HSL: 210, 16%, 98%) providing a clean, light, and airy base for the interface, enhancing readability and focus.
- Accent Yellow: #FFD100 (HSL: 47, 100%, 50%) for high-contrast elements such as calls-to-action, rewards highlights, and interactive components, bringing energy to the design.
- Secondary Dark Blue: #003A8F (HSL: 215, 100%, 28%) for depth, hierarchy, and distinguishing key information without clashing with the primary blue.
- Headlines will use 'Space Grotesk' (sans-serif) for a modern, digital, and competitive appearance, suitable for impactful titles.
- Body text will utilize 'Inter' (sans-serif) for excellent legibility and a clean, objective aesthetic, essential for quiz questions and leaderboards.
- Use clean, bold, and sporty icons with a digital edge. Emphasize football, flags, trophies, and avatar elements that resonate with the World Cup theme and competition.
- Prioritize a 'mobile-first' responsive design with intuitive swipe navigation and prominent, easy-to-tap buttons to ensure optimal usability on mobile devices. Utilize a grid-based card system for organizing content like categories and leaderboards, maintaining a clean and modern appearance.
- Incorporate subtle hover effects (like a glow) on interactive elements, smooth transitions for category filtering, and engaging countdown timer animations to enhance user experience and highlight real-time aspects.
